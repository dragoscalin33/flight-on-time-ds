Step 1 — User Question

The user types a question in plain language — no forms, no dropdowns, no IATA codes required. The system understands intent, airline, airports, and date/time automatically.

It works in any language. Here are real examples that the assistant understands:

🇪🇸  "Mi vuelo de GOL de Guarulhos a Santos Dumont el 28 de marzo a las 12h, va a atrasar?"

🇬🇧  "Which São Paulo airport has fewer delays?"

🇧🇷  "Meu voo da AZUL de Brasília para Recife vai atrasar?"

Step 2 — RAG Retrieval

The question is converted to a vector embedding using sentence-transformers (all-MiniLM-L6-v2) and searched against the knowledge base in ChromaDB.

Knowledge base contains 26 chunks from 3 curated documents:

• airport_guide.md — Delay patterns for 10 major Brazilian airports

• delay_factors.md — Weather, operational, temporal, and geographic factors

• model_info.md — CatBoost model details, metrics, and feature importance

Top 3 most relevant chunks are injected into the LLM system prompt as context.

Step 3 — LLM Reasoning

The LLM receives the user's question + RAG context and decides what to do:

• Direct answer: If the question is about general knowledge (e.g., "why does Congonhas have more delays?")

• Tool call: If a prediction is needed, the LLM autonomously calls the CatBoost ML model

Supports dual providers:

• Claude API (Anthropic) — Best quality, requires API key

• Ollama (local) — Free, runs on your machine, no data leaves your computer

The LLM abstraction layer means switching providers requires changing one env variable.

Step 4 — Tool Calling

The LLM can autonomously invoke 3 tools:

• predict_flight_delay — Calls the CatBoost ML model trained on 2.2M flights

• lookup_airport — Searches the airport database (198 airports)

• check_weather — Gets real-time weather from OpenMeteo API

Tool results are fed back to the LLM, which generates the final human-readable response. This is NOT prompt engineering — the LLM actually executes API calls and uses real data.

Step 5 — Final Response

The response includes:

• Natural language answer — Tailored to the user's language

• Risk level — 🟢 Low (<35%) / 🟠 Medium (35-70%) / 🔴 High (>70%)

• Source citations — Which knowledge documents informed the answer

• Tools used — Which ML models/APIs were called

• Latency — Response time for observability

Every response is transparent about where its information comes from.

System Components

📚 RAG Pipeline ChromaDB
Knowledge base chunked (500 chars, 100 overlap) and embedded with sentence-transformers. Cosine similarity search returns top-3 relevant chunks per query.
  • 3 curated domain documents (aviation, weather, model)
  • 26 indexed chunks in vector store
  • Local embeddings — no API cost
🔧 Tool-Calling Engine 3 TOOLS
LLM autonomously invokes real ML models and APIs. Tool definitions follow the Anthropic tool-use spec. Results are fed back for natural language generation.
  • Deduplication prevents repeated calls
  • Error handling with graceful fallback
  • Anti-hallucination guards when tools fail
🧠 LLM Abstraction DUAL
Provider-agnostic design supports cloud and local LLMs through a unified interface. Switch with one env variable.
  • Claude API (Anthropic) — production quality
  • Ollama (local) — free, private, offline
  • Same tool-calling protocol for both
📈 Evaluation Pipeline 10 CASES
Automated evaluation across predictions, knowledge questions, lookups, and multilingual queries.
  • Tool accuracy — did it call the right tool?
  • Context accuracy — did RAG retrieve relevant docs?
  • Latency tracking per query
⚡ FastAPI Service PORT 8001
RESTful API with auto-generated Swagger docs. Session-based chat history and CORS support.
  • POST /chat — send message, get AI response
  • GET /chat/history — conversation replay
  • GET /health — service status
🗨️ React Chat Widget EMBEDDED
Floating chat widget integrated into the existing Flight on Time dashboard. Tailwind CSS styling.
  • Suggestion buttons for common questions
  • Tool-call badges and source citations
  • Typing indicator and session management
